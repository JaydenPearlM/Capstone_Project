# 💰 Cache Budgeting App

A full-stack **financial budgeting application** built with the **MERN stack**  
(MongoDB, Express.js, React, Node.js).  

Developed as part of the **TechWise Capstone Project**, this app helps users manage expenses, savings goals, and debts in one secure platform.  

---

## ✨ Key Features
- 🔐 **User Authentication** — secure login with JWT & bcrypt  
- 💳 **Card & Debt Tracking** — manage balances, APRs, and due dates  
- 📂 **Categories & Transactions** — CRUD operations for budgeting  
- 📊 **Credit Utilization** — track usage with progress indicators  
- 📑 **CSV Export** — generate custom financial reports  
- 🏦 **Plaid Integration** — (sandbox) connect bank accounts & fetch transactions  
- 🛠 **Error Logging** — centralized with Winston  

---

## 🛠 Tech Stack
- **Frontend:** React, CSS, Chart.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB + Mongoose  
- **Auth & Security:** JWT, bcrypt, helmet, express-validator  
- **API Integration:** Plaid (sandbox)  
- **Dev Tools:** Postman, Winston Logger, Nodemon

## How to Run

> **Note:** The project is currently only available in **development mode**.

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your machine.

### 1. Install dependencies

#### Backend

```bash
cd server
npm install
```

#### Frontend

```bash
cd client
npm install
```

### 2. Run in Development Mode

#### Backend

```bash
cd server
npm run dev
```

#### Frontend

```bash
cd client
npm run dev
```

### 3. Access the Application

* Open your browser and navigate to:

  ```
  http://localhost:3000
  ```
* Backend API runs on:

  ```
  http://localhost:5000
  ```
